# Overbalancing

A Rust and Bevy balance puzzle game, inspired by Swing (1997).

Project documentation is written in HTML: [development](docs/development.html),
[specifications](specs/index.html), [architecture decisions](adr/index.html),
[license](LICENSE.html). Agent instructions are in [AGENTS.md](AGENTS.md).

```sh
cargo run -p overbalancing-app
```
