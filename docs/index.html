Current scope

Owner-accepted gameplay includes level-driven supplies, fixed stacks, animated wrapped launches, compression, joker cascades, score and automatic level progression. Appearance refinements and special-ball proposals have their own review and acceptance status in the linked guides and specifications.

Build checks and a displayed scene do not establish runtime compatibility on every device. Platform runtime evidence is tracked in the first-view change.
