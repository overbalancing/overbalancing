Overpalancing documentation

Project documentation

Overpalancing is a Rust and Bevy game inspired by Swing (1997). Linux is the primary development platform; Windows, macOS, iOS and Android are build targets.

  • Architecture decision records
  • Specifications and change proposals
  • Development and review workflow
  • Verification evidence
  • Architecture and dependency assessment
  • Rust API reference (generated during documentation deployment)

Current scope

The foundation establishes the workspace, collaboration rules and continuous integration. The first view is a separate feature: a primitive rendering of four seesaws, weighted colored balls and a dispenser. Full game resolution rules are future work.

Build checks and a displayed scene do not establish runtime compatibility on every device. Platform runtime evidence is tracked in the first-view change.
