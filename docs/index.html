Current scope

Owner-accepted gameplay includes level-driven supplies, fixed stacks, animated wrapped launches, compression, joker cascades, score and automatic level progression. Merged stars, bombs and stones add special contacts, rewards, blast chains and capacity expansion. Utility-ball work and later heart/black-hole features retain their own review and acceptance status in the linked specifications.

Build checks and a displayed scene do not establish runtime compatibility on every device. Platform runtime evidence is tracked in the first-view change.
