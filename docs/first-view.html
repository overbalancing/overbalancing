Project documentation

First view

This selection-only prototype shows four seesaws, weighted color balls and a movable chute. It does not yet implement dropping, matching, compression or physics. No external art is required.

cargo run -p overbalancing-app

The window title is Overbalancing — first view. The earlier foundation window named Overbalancing intentionally contains no scene.

Use Left/Right, A/D or click/tap a lane to select the chute position. R/B/Y identify colors independently of color vision; numbers identify weights. Split circles illustrate future two- and three-color jokers.
