Structure

Separate platform presentation from reusable game-domain logic. Keep adr/, specs/ and docs/ as sibling documentation roots. Publish their paths intact alongside generated api/ rustdoc.

Automation

Provide Renovate, audit, nextest, dependency deny, formatting, Clippy, scheduled MSRV and documentation deployment. Include Linux, Windows, macOS, iOS and Android build coverage. The MSRV schedule runs nightly using the declared minimum stable toolchain.
