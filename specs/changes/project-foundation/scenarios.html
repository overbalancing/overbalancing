Observable acceptance

  1. Given a clean checkout with declared prerequisites, Cargo recognizes the workspace and the documented development commands run.
  2. Given a pull request, configured checks report formatting, lint, tests, security and dependency policy results.
  3. Given the scheduled MSRV workflow, it selects the declared minimum stable toolchain and checks supported workspace code.
  4. Given a Pages deployment, the documentation home links to readable ADR, spec, docs and generated API pages.
  5. Given a proposed ADR approval, repository guidance reserves its merge to the owner.

Evidence
